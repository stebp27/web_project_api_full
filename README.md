# Tripleten web_project_api_full

This project combines and enhances the frontend and backend of the Around The U.S. application previously developed.

It is a simple social media-style Single Page Application (SPA) for photo sharing, where users can upload photos of their adventures, like them, delete them, and customize their profile by editing their personal information or avatar.

The application includes user registration and login functionality, as well as JWT-based authentication to securely preserve user sessions.

The frontend is built with React, the backend is developed with Express, and the application uses MongoDB as its database.

## Server Access

- Frontend: https://around19.mooo.com
- Backend API: https://api.around19.mooo.com

# Tripleten web_project_api_full

Este proyecto reune y mejora el contenido de el frontend y backend de Around The U.S. hecho anteriormente.

Es una SPA sencilla en formato red social de photos sharing donde podemos publicar fotos de nuestras aventuras, darles like, borrarlas o decidir mejorar nuestro perfil editando nuestras informaciones o nuestro avatar.

Hay un proceso de login y registracion para nuevos usuarios, pero también cuenta con un sistema de preservación de la info usando jwt.

El frontend es en React, el backend en express y cuenta con un db en MongoDB.

## Acceso al servidor

- Frontend: https://around19.mooo.com
- Backend API: https://api.around19.mooo.com
